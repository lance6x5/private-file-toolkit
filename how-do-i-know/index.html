What happens to your files

When you choose or drop a file, your browser reads it into this tab’s memory. Fileward’s code, which your browser downloaded when you opened the page, processes it right there, using JavaScript and WebAssembly in background threads (Web Workers). The result is created in memory and saved with an ordinary download link that points to your own device.

At no point is a file, a file name or any information about your files sent anywhere. There is no server that could receive them: Fileward is a set of static files hosted on GitHub Pages, with no backend, no accounts, no analytics and no cookies.

Check it yourself

  1. Watch the network. Open your browser’s developer tools (F12, or ⌥⌘I on a Mac), choose the Network tab, then use any tool. You will see Fileward’s own scripts and styles load from lance6x5.github.io, and nothing being sent when you process a file.
  2. Go offline. Open a tool, then turn off Wi-Fi or switch on airplane mode. Drop a file: the tool still works, because everything it needs is already on your device.
  3. Read the code. Fileward’s source is public on GitHub. The build is produced by a public GitHub Actions workflow from that source.

    The lock on the door: Content-Security-Policy

    Every Fileward page carries a Content-Security-Policy, a rule set that your browser enforces. Its connect-src 'self' rule means the page is not allowed to open a connection to any other website, so even a bug could not upload your files. Background workers are started in a way that makes them inherit the same rule. Scripts may only come from Fileward itself; no CDNs or third-party code are loaded. This page’s policy is:

    
      
    

      
    
        
    What Fileward stores on your device
    
        
    Only your last-used settings (such as the compression quality) in this browser’s local storage, and an offline copy of the app in the browser cache. Your files are never stored.
    
        
    
          
          
          
          
        
    
      
    

      
        
    
          
    Reset all data?
